Watermark From Reference

Reads telescope, camera, filter, exposure and capture-date metadata straight from your FITS/XISF files and stamps it onto a copy of your image as a fully customizable, drag-to-position text watermark.

Features

Everything is read directly from your capture files — nothing is typed in by hand unless you want it to be.

📡

Reads real acquisition metadata

Telescope, camera, mount, filter, target, exposure, date, focal length, RA/Dec, gain, sensor temp and site location — straight from FITS keywords or XISF properties.

✅

Pick exactly what shows

Check only the fields you want in the watermark. A field is skipped automatically if the reference doesn't actually contain that data.

🎨

Full style control

Text size, text color (presets or a custom RGB picker), background opacity from fully transparent to opaque, and left/center/right line alignment.

🖱️

Live, draggable preview

See the watermark on a thumbnail of your actual image. Drag it anywhere, or snap it into place with the 3×3 corner/edge/center position grid.

📝

Optional custom message

Add your own line — name, website, copyright note — that wraps and auto-fits alongside the metadata instead of ever running off the image.

🛡️

Non-destructive

Always creates a brand-new image window. Your original target image is never modified.

Install

Requires PixInsight 1.9.4 or later (V8 script runtime).

Option A — Update repository (recommended)

  1. In PixInsight: RESOURCES → Updates → Manage Repositories → Add
  2. Paste this URL:
    https://raw.githubusercontent.com/pgirish007/pixinsight-watermark-from-reference/main/updates/
  3. RESOURCES → Updates → Check for Updates, apply the update, then restart PixInsight.
  4. Find it at SCRIPT → AstroByGirish → Watermark From Reference.

Option B — Manual install

  1. Download WatermarkFromReference.js from the GitHub repository.
  2. In PixInsight, use SCRIPT → Execute Script File... and select it, or
  3. Drop it into your PixInsight scripts/ folder and use the Script Editor's Feature Manager to install it permanently under the Scripts menu.

Usage

Eight steps from opening the script to a finished, watermarked image.

  1. Open SCRIPT → AstroByGirish → Watermark From Reference.
  2. Under Target image, pick the view you want watermarked.
  3. Under Reference metadata source, choose an already-open view, or browse to a FITS/XISF file on disk. Prefer an original light frame over a stacked master — some values (gain, focal length) are only reliable straight from the camera's own header.
  4. Under Watermark fields, check whichever fields you want. Telescope, Camera, Filter, Exposure and Date/Time are checked by default. Checking Site Location lets you also resolve it to a city/state name via the free OpenStreetMap Nominatim service (needs internet) — leave it unchecked to stay fully offline.
  5. Optionally type a Custom message — added as its own line, exactly as typed.
  6. Under Watermark style, set text size, text color, background opacity, and text alignment.
  7. Click Preview Metadata. Drag the watermark in the live preview, or use one of the nine Position preset buttons for a quick placement.
  8. Click Add Watermark (new image). A new image window is created with the watermark baked in — your original is left untouched.
